# 项目交接与状态模板

## 读取边界

交接记录是检索入口与连续性提示，不能替代当前原剧本。读取当前场次及必要前后文，确认材料版本与用户最新尾帧。项目文件名、内部索引只在有访问权的上下文使用，不写进公开通用技能。

项目专属人物、画幅、伤势、轻奇幻机制与台词不迁移到别剧。用户要求查看整个剧本时必须实际读取全剧；局部续接不需要为形式完整读取无关集数。未能取得原件时仅依可见材料工作并说明边界。

## 精简交接内容

```text
项目与范围：剧名、集数/场次、本次负责范围。
当前来源：原剧本及版本、当前稿、最新有效图/视频、用户最新确认。
原稿事实：事件、人物关系、逐字台词、关键道具、不可改结果。
项目条件：画幅、风格、角色/声音/场景/道具引用、时长及声音要求。
当前尾态：相对地标位置、姿态朝向、未完成动作、持物手、伤势、门灯与损坏。
原稿待解冲突：时间/日夜、戴帽、道具位置、前后动作等，并列证据。
制作选择：为镜头成立所选的左右手、取放衔接、机位与调度；注明非原文事实。
下一段入口：必须承接的姿态、声音、行动与未定事实。
```

## 处理常见原稿矛盾

剩余时间先后不一致、白天后紧接夜晚：保留台词与日夜证据，指出冲突，不静默改成一致。物体已放进罩内，人物又被写成抱在胸前：说明物件位置矛盾，最小兼容拍法应标作制作选择，不能宣称原稿本就如此。

道具从枕下变床头、礼帽摘下后又飞起：核对是否存在放置或重新佩戴；缺失时提出最小连接或保留待定，不把临时省略当原稿没有该物件。管状道具被放下或掉落后再次挥击，明确可达落点与重新拿起。

小动物被撞击后某后腿失能：持续记录受力、落点和后续支撑能力。剧情有特定称量、晶格或掌温机制时按故事设定表达，不冒充现实科学或普通烹饪事实；称量结果不能在测量完成前出现。

助手上次写过的左右手、位置兼容法与拆镜选择不自动成为用户定稿；当前原件和用户新确认优先。每次续接核对状态后继续，不机械复制整份交接表进分镜。
