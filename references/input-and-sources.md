# 输入、参考图与规则优先级

## 收集必要输入

从现有材料提取：剧名与集数、负责片段、当前原文及必要前后文、最新分镜、角色与服装、声音引用、场景与道具、参考图用途、上一尾帧、当前伤势和持物状态、画幅风格、目标时长及平台限制。无需为所有字段齐全反复询问；用户已给的信息直接使用。

当前没有原剧本时，仅按用户粘贴的剧本或分镜设计，不补造所谓原文。局部修改保留未请求部分；如果更改影响下一镜开头，补最小连接并明确范围。关键角色身份、动作结果或台词矛盾才询问；一般机位与剪辑选择自行决定。

## 参考图职责

| 材料 | 读取内容 | 不自动继承的内容 |
|---|---|---|
| 首帧、尾帧、当前有效视频帧 | 实际坐标、动作阶段、持物、服装、伤势与门灯状态 | 图中错误身份或明显生成缺陷；遇冲突应核对 |
| 站位图 | 位置、距离、朝向、层级、地标关系 | 动作、景别、机位与最终材质 |
| 角色图、造型图 | 身份、面孔、体型、年龄感、发型与当前服装 | 未指定的站位、表演和光源 |
| 场景图 | 建筑结构、门窗、楼梯、通道、固定光源 | 未经确认的剧情行动 |
| 道具图 | 结构、颜色、外形及有依据的人体比例 | 无尺标时的精确实测尺寸 |
| 错误生成图 | 错误位置、身份、轴线、动作或道具症状 | 新的正确空间母版 |
| 白膜、线稿、三视图、拼版 | 用户指定的几何、比例或身份信息 | 白膜材质、多格拼版、文字标注与最终视频首帧 |

同图可以承担多个明确职责，不能以“职责隔离”为由删掉用户指定的信息。真实视频中的当前状态与正式剧本冲突时先定位问题；不能把错误视频无条件升格为剧本事实。

## 来源与优先级

先执行本次明确要求，再执行当前项目最新确认；原剧本与指定资产提供事实，未授权修改的剧情、台词与角色身份必须保留。旧稿和历史建议只作参考。用户明确要求改剧情时标明这是新要求，而非宣称原稿本就如此。

原件中的时间、日夜、戴帽、持物、道具位置或伤势有冲突时，说明冲突并保留待定处，或提出不改变关键剧情的最小制作选择。区分“原文如此”“用户确认”“本次拍法”；助手写过、未被纠正、或者看起来合理都不等于用户已定稿。

本技能整合已确认的分镜项目文档和新版执行规程。无当前格式指定时采用现行完整模板；仓库旧版的逐镜时间/焦段、约4秒插反应、细碎身体分解以及固定格式不作为现行默认。它们只有在用户本次明确需要时才启用。

镜头语言术语、光学关系、声源或平台能力有不确定时，查可靠当前来源；需要联网时遵守当前工具规则。外部资料用于核验专业事实，不能覆盖用户剧情和本轮格式。没有核验过的模型时长、声音能力或成功率不得当成已确认参数。

## 项目适用性

真人、3D、二维、横屏、竖屏均适用。继承已确认的风格母版，不默认使用某个相机、胶片、UE渲染、肤色、国别或演员造型；确需统一风格时按用户材料写本段必要约束，不顺手重做全剧资产。

有真实资产引用时准确保留；无编号时用角色名或“待绑定”，不虚构图像、角色或音频编号。字幕提取格式只用于该任务，不反向删改分镜中的原文标点。无配乐是本技能缺省声音选择，不能覆盖用户已要求的音乐。
