# 错误定位与修复

先区分剧本矛盾、分镜设计错误与生成模型错误；不要把失败截图自动当成新空间。明确替换范围，保留有效设计；改动影响后续时同步必要连接。一次只修主要变量是诊断策略，不能用它拒绝修正本次已经明确的多个连续性问题。

| 症状 | 核查原因 | 落实修复 |
|---|---|---|
| 甲的台词被乙说出、音色漂移 | 角色、造型、音频与声源混淆 | 明确当前说话人与可见角色；听者不代说，跨镜音频持续 |
| 反应拍错人或提前反应 | 按方便取景切人，忽略信息影响 | 找出实际被反驳、威胁或告知者，让反应发生在信息之后 |
| 后续片段重新排位 | 只写同上，或混用旧稿 | 每组写必要起始位置与画外状态，新状态持续下传 |
| 背景和视线不符、同侧仍越轴 | 只写口头同侧，未核查实际机位 | 用地标检查机位、主轴、拍摄方向和全运动路径 |
| 为双人构图让人物瞬移 | 把画面左右当现实左右 | 保持地面位置，改摄影机、取景或纵深构图 |
| 左侧进入变成纵深走来 | 缺起点、入画边和路线 | 写清相对地标起点、画面边缘、路径及终点 |
| 全景只剩两人 | 把近景裁切理解为人物离开 | 区分现场人员与本镜入画清单，按真实在场恢复全景 |
| POV出现本人正脸或多余手 | 主观和客观镜头混写 | POV遵守眼位；需要拍本人时切客观镜头，指定唯一持物手 |
| 环顾看不到后方人群 | 观看角度、姿态和空间不成立 | 核查可视范围，用合理转身或拆镜完成，不编造几何 |
| 小道具变成巨大证书 | 只写泛称，缺尺度与比例 | 绑定手掌/身体比例、外形、朝向；特写不改变现实尺寸 |
| 已收起道具、帽子或服装自动恢复 | 状态未传播或缺重新取戴 | 保留收存位置，补有依据的取出/戴回，不凭空复原 |
| 挥击没有命中、物体无故飞走 | 接触点、方向、支撑或结果缺失 | 让准备、接触、受力及结果可读，必要时分镜匹配 |
| 受伤肢体继续正常承重 | 只看当前镜，不继承伤势 | 持续限制抓握与支撑能力，按剧情设计代偿动作 |
| 门倒两次、破罩代替内容物破碎 | 初始结构与独立对象混淆 | 分清施力、连接损坏、倒落、内容物变化与最终状态 |
| 同镜动作过多或动物操作超负荷 | 并行行动、手部任务、尺度不合理 | 按因果阶段组织，减少同镜负载，不改故事结果 |
| 台词说不完、时长虚假精确 | 先定数字后塞表演，重复计算并行时间 | 自然朗读估时，删冗余动作；仍超限则拆组，计划不冒充实测 |
| 膝上画面变脸部近景 | 景别名与取景范围冲突 | 按真实范围取景并准确命名 |
| 所有镜头固定或缓推 | 没先确定观看价值 | 按揭示、跟随、关系、强调和动作需求重选运动 |
| 只堆负面词但问题不变 | 未修改致错空间或行动 | 改具体机位、入画、接触、声源与状态，负面仅补关键风险 |

局部修改时用一两句话说明真实矛盾（用户只要正文时省略），再给完整可替换的目标内容。不能将本次“反应拍某人”“末尾两秒全景”“道具在右手”等个案推广为永久规则。没有生成验证时不得保证绝对不串角、不越轴或一次成功。
