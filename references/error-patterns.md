# 已验证的错误类型与修复决策

| 错误 | 原因 | 修复 |
|---|---|---|
| 士兵台词由军官说出 | 混合角色资产，发言人未隔离 | 重新绑定姓名、外貌、制服、角色及声音；发言镜头按用户要求单人取景 |
| 切错反应对象 | 按方便取景而非台词作用选人 | 识别被反驳、受威胁或获知信息的人；本案核验成立拍质疑者 |
| 后续片段重新排位 | 只写“同上” | 每段重复资产与逐人第0秒状态 |
| 角色不看对话对象 | 缺真实转身，镜头仍用旧背景 | 先建立转身，再按新拍摄方向确定背景与视线 |
| 蓝证变大证书 | 只写“证件”“薄册” | 绑定手掌比例、封皮、开合与尺寸制作设定；特写不增大道具 |
| 已收证件重新出现 | 状态未传播 | 保存持有手与口袋状态，取出必须写过程 |
| POV出现主角正脸和第三只手 | 主客观混写 | 环顾用纯POV；拍本人展示则用客观镜头，指定唯一持证手 |
| 环顾转角无法看到后方人群 | 用不够的角度强行扫到背后 | 核对真实观察范围；让躯干合法转向或拆镜，不编造几何 |
| 从左侧入画变为从闸机向镜头走 | 缺起点与路线 | 定义左侧地面起点、横向路径、空隙和终点 |
| 全景只剩两个人 | 将近景排除写成全局删除 | 单镜入画清单与现场人员清单分开；全景明确恢复全体可见人物 |
| 同侧仍越轴 | 只有口头“同侧”，摄影机实际跨人物连线 | 用统一平面基准核对每台机位；不机械套左右各35度 |
| 同镜过长或动作拥挤 | 多组行动塞进一个镜头 | 按行动组切镜，动作匹配；关键站位变化按全景预算交代 |
| 压缩台词后无法正常说完 | 停顿和反应挤占朗读 | 先按自然语速估时，删冗余动作；仍放不下则明确说明并拆段 |
| 要膝上画面却变成面部近景 | 景别名称与取景范围冲突 | 优先按用户指定头顶至膝盖范围，准确命名膝上中景 |

不要将某次修正推广成所有作品的固定要求。例如“反应应拍Jake”“最后2秒全景”“蓝证在右手”只属于相应剧情；可迁移的是选择因果正确的反应者、遵守最新尾帧要求和持续跟踪持物状态。
