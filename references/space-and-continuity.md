# 空间、资产与连续性

## 建立空间和摄影轴线

先确定门、窗、柱、床、工作台、通道、台阶、障碍和固定光源，再确定人物相对地标的位置、前后距离、朝向和视线，最后布置摄影机。内部可用简单坐标或平面图辅助，但不向成品强塞数字资产表。

区分三种左右：现实空间的固定方向、人物自身左右、某机位的画面左右。换机位后画面左右可能变化，人物现实位置不能跟着搬动。用共同地标核查机位、背景、视线和移动方向是否互相支持。

依据人物连线、运动方向或主要交互建立主轴和观察侧，核查整条摄影运动路径。只写“全在大厅一侧”不足以保证同轴。多人物场景先确定本段主关系与视线，切换关系时重新确认工作轴；不把所有人物关系硬套成一条线。

默认避免意外越轴。确需换侧时通过可辨认的连续运动、中性镜头或清晰的空间重建让观众理解；中性镜头不是自动修复所有混乱的万能切镜。不要因角色自己转头便假定摄影轴已合法改变。

## 入画与调度

每镜明确主次主体、景别与实际画框、前后层次、遮挡和必要背景。单人镜头用摄影机与裁切隔离他人，不通过让其他角色离开真实位置解决。肩、手、影子、镜面反射与虚化轮廓也算可见元素，按用户的“谁不入画”要求检查。

画外人物仍存在，记录其相对地标位置。需要全景时呈现实际在场者，不把近景裁切变成角色消失；人数依据画框、纵深和调度决定，不规定三人必裁、四人不可同框。

竖屏避免无依据的横排群像；可用前后层次、局部和纵向调度组织关系，但不能为竖幅改掉真实站位。人物入画要写清起点、画面边缘、路线、避让和终点。“左侧进入”不能改成从正后方迎面走来。

站位实质变化后，按剧情需要用关系画面重建，不强制拍全景。若用户指定全景次数、末尾稳定全景或“不切全景”，优先满足并用其他方式交代必要关系。

## 维护最小状态记录

| 对象 | 核对项 |
|---|---|
| 人物 | 现实位置、姿态、朝向、视线、移动阶段、画内外 |
| 身体与服装 | 伤势、支撑能力、干湿、血迹、帽子及其他穿戴 |
| 道具 | 数量、尺寸与人体比例、归属、左右手、开合、朝向、连接、收存、落点、损坏 |
| 场景 | 门窗、灯光、设备、玻璃、障碍、物件散落与可行走空间 |
| 声音 | 实际说话者、现场/内心/电话/旁白、对白进行到哪里 |

状态改变后传播到下游镜头，不回滚到旧稿。首帧或最新有效尾帧为当前状态证据；它与剧本矛盾时先核对，不把错误生成强当新事实。内部记录不要求每镜重复全部字段，只写影响生成与连续性的必要内容。

持物同时约束身份、外观和人体比例，特写放大构图不能放大道具。没有尺标不能声称图片实测厘米数；必要尺寸属于制作选择。证件收入口袋后不能下一镜自动举起，铁管落地后不能无取物过程出现在手中。

攻击或交接核查施动手、受力点、支撑、方向、脱手和落点。受伤手腕与失能后腿不能因换镜恢复正常；摘下的帽子、脱掉的披风、断开的连接和碎裂的物件不能自动复原。

## 光源与跨组衔接

固定光源与真实空间一致。人物换向、摄影机换侧后受光面与背景可变，不能为保持相同视觉左右而搬灯或镜像场景。夜景、室内色温和具体项目禁用元素只按项目确认继承。

每个独立生成组重述必要角色、场景、状态和起始站位，不用“同上”承担全部条件；有真实资产引用时准确复用，不要求每次硬切复制庞大资产清单。切镜涉及身份易混时在正文明确当前角色与造型。

本组尾态对齐下一组首态：谁在哪里、看向哪边、什么动作尚未完成、谁持物、损坏是否持续、对白是否接续。若用户要求尾帧可截图，留出合理稳定状态；否则不为截图把每组强行停住。
