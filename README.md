# 短剧分镜导演与严格审评

一个从剧本、旧分镜和参考图出发，完成空间连续性、镜头、运镜、动作表演、对白声画与节奏设计，并在交付前修订的 Codex Skill。支持真人、3D、二维及不同画幅。

## 完整流程

读取当前原文与必要前后文 → 确认任务边界与项目条件 → 判断戏剧重点 → 建立参考图职责、空间轴线和状态记录 → 设计景别机位与组合运镜 → 组织动作、对白、反应和声音 → 估算并分配生成组时长 → 核对剧情、台词与连续性 → 修订后输出分镜提示词。

支持新设计、实质优化、跨组续接、局部修改、补镜、生成错误修复、台词核对和严格审评。不会仅为格式齐全堆形容词，也不会擅自删改正式剧情和台词。

## 调用

将仓库内容放入 Codex 的个人 Skills 目录中，以 `direct-drama-storyboards` 作为文件夹名称，确保根目录直接包含 `SKILL.md`。调用：

```text
使用 $direct-drama-storyboards 读取原剧本与必要前后文，设计或优化下面这段分镜。完整保留剧情与台词，直接输出审评后的分镜提示词。
```

可一并提供：本次范围、角色与声音资产、场景与道具图、每张参考图用途、上一尾帧、画幅风格、时长及平台限制。缺少非关键摄影条件时可采用可撤销制作选择，不虚构资产编号或原文台词。

## 默认输出

视觉锚点 → 站位 → 环境状态 → 画面 → 总时长 → 负面约束。

每镜以连贯段落呈现，最多三段，保留景别、视角、高度、运动方式、构图背景、动作表演、声音和必要尾态；默认不加镜号、逐镜秒数或焦距光圈数值。单组默认4—30秒，标整数目标总时长；它是计划，不冒称已实测。用户本次明确格式与最新项目确认优先。

长对白按语义、行动和信息安排观看发展，不机械按秒数切反应。默认声音为人声、环境和同步动作音；已要求音乐时按要求设计。

## 文件

- `SKILL.md`：任务路由、完整导演流程、输出及审评。
- `agents/openai.yaml`：界面名称、默认调用提示与图标。
- `references/input-and-sources.md`：来源、参考图职责、规则适用性。
- `references/narrative-and-shot-design.md`：叙事、景别、机位、剪辑与观看价值。
- `references/space-and-continuity.md`：主轴、真实站位、入画清单和状态连续。
- `references/motion-and-action.md`：运镜路径与节奏、动作接触、受力、破坏和动物尺度。
- `references/dialogue-and-review.md`：逐字台词、声音属性、时间和交付审评。
- `references/output-and-preflight.md`：完整与紧凑格式、局部交付和针对性约束。
- `references/error-patterns.md`：常见生成错误的定位与具体修复。
- `references/project-handoff.md`：项目交接、事实冲突及制作选择的区分。
- `references/regression-cases.md`：技能维护的迁移与回归场景。

每个独立生成组应具备必要起始条件与可衔接尾态。仅有文字时不声称成片终审；实际效果仍需用生成视频与配音验证。调用技能不授权公开剧本、人物图、私人文件索引或整个项目。
