# AI 连续性分镜提示词 Skill

一个面向 AI 视频、欧美短剧、剧情对话和大连场调度的 Codex Skill。它把剧本、角色资产、场景图、站位图和上一片段尾帧整理为可以直接复制到视频生成平台使用的中文分镜提示词。

这个 Skill 的重点不是堆叠画质词，而是解决 AI 视频生产中最容易反复出错的连续性问题：人物换位、越轴、对白串角、反应镜头切错人、道具忽大忽小、近景之后其他角色消失，以及下一片段无法衔接上一片段。

## 适用场景

- 根据完整剧本拆分一集或多集 AI 视频分镜。
- 根据角色图、场景图和站位图建立多人空间关系。
- 为 4—30 秒生成片段设计多个连续小镜头。
- 修改已经生成失败的镜头，例如越轴、串脸、错误入画方向或错误道具状态。
- 处理多人争吵、审讯、会议、大厅对峙和边走边说等复杂调度。
- 在长对白中加入正确的听者反应镜头，同时保持原说话者声音连续。
- 为大连场持续记录人物坐标、门窗状态、道具归属和最后尾帧。

它不会替用户改写正式剧情，也不会虚构角色编号、声音编号、道具资产或场景资产。最新用户要求与最新有效参考始终优先。

## 核心能力

### 1. 独立片段可直接生成

每个正式生成片段都会重新说明当前使用的角色、声音、服装、场景、道具和第 0 秒站位。后续片段不会只写“继承上一段”或“资产同上”，因此可以单独复制到视频平台生成。

### 2. 站位和轴线连续

Skill 会先确定统一观察方向，再记录每个人的屏幕左右、前后层级、现实距离、身体朝向、视线方向和画外位置。镜头切换时保持同一轴线侧，避免人物左右互换或对话对象错误出现在说话者身后。

### 3. 对白、音色和反应镜头绑定

每次硬切都会重新绑定可见角色资产。说话者姓名、角色、服装和音频保持一致；听者在反应镜头中闭嘴，原说话者以现场画外声继续。反应对象根据台词的实际影响选择，例如权威结论打脸质疑者时，优先切质疑者，而不是机械地切友方人物。

### 4. 道具与场景状态跟踪

Skill 会记录道具由哪只手持有、尺寸与人体比例、封面方向、开合状态和收存位置。证件一旦放入口袋，后续镜头不会自动重新出现；门、闸机、灯光和扫描状态改变后也会持续继承。

### 5. 参考图职责隔离

不同参考图承担不同职责：

- 首帧或尾帧图：继承实际坐标、动作和道具状态。
- 站位图：只参考位置、距离、朝向和前后层级。
- 角色图：锁定人物外貌、体型和服装。
- 场景图：锁定建筑、通道、楼梯、门窗和照明。
- 道具图：锁定结构、颜色、细节与人体比例。
- 错误生成图：只用于诊断错误，不自动成为新的站位依据。

白膜、线稿和三视图不会被误当成最终材质或视频首帧。

### 6. 针对生成错误进行局部修复

用户只要求修改一个镜头或一个时间段时，Skill 会先指出具体矛盾，再只重写目标范围及必要衔接，不重复整段无关内容。修复会落实到机位、方向、时间、口型、人物隔离和尾帧状态，而不是简单增加大量负面词。

## 标准工作流程

```text
剧本与负责集数
      ↓
角色、声音、场景与道具资产
      ↓
判断每张参考图的唯一职责
      ↓
建立人物坐标、轴线和状态记录
      ↓
按对白、动作和情绪节拍拆分片段
      ↓
为每个片段重写资产与第0秒站位
      ↓
设计关系镜头、反应镜头和必要全景
      ↓
检查台词、口型、音色、道具与尾帧
      ↓
输出可直接复制的完整中文提示词
```

## 推荐输入方式

为了得到稳定结果，建议一次提供以下内容：

1. 当前负责的集数和完整剧本。
2. 本集涉及的人物及角色、声音资产引用。
3. 场景图、人物图、道具图和最新站位图。
4. 每张图的用途，例如“只参考站位，不参考动作和景别”。
5. 上一片段尾帧或当前人物、道具、门和设备状态。
6. 总时长、片段数量、全景次数、画幅和平台限制。
7. 已经出现的生成错误及希望修改的时间段。

示例请求：

```text
使用 $write-continuous-storyboards 重写第29集片段4。
总时长28秒，9:16竖屏，最新图片只参考站位，不参考动作和景别。
士兵的长对白中切一次Jake闭嘴反应；Brittany必须从画面左侧入画。
倒数第二镜是Emma单人特写，最后2秒给全员站位全景，全程不要越轴。
```

## 输出内容

一个完整片段通常包含：

- 角色、声音、服装、场景和道具资产。
- 每张参考图的具体职责。
- 画幅、风格、环境声和口型规则。
- 独立第 0 秒人物站位与画外连续状态。
- 对话轴线与摄影机允许区域。
- 连续时间轴上的焦段、景别、机位高度、方向、距离和运镜。
- 演员动作、微表情、对白起止时间和听者反应。
- 尾帧站位、道具、门灯和下一镜衔接状态。
- 只针对当前风险的强制限制。

## 安装

### 方法一：Git 克隆

将整个仓库克隆到 Codex 的个人 Skill 目录：

```powershell
git clone https://github.com/wanghaho/ai-storyboard-skill.git "$env:USERPROFILE\.codex\skills\write-continuous-storyboards"
```

重新打开 Codex 任务后，即可通过以下名称调用：

```text
$write-continuous-storyboards
```

### 方法二：下载 ZIP

1. 在仓库页面点击 `Code` → `Download ZIP`。
2. 解压后将文件夹命名为 `write-continuous-storyboards`。
3. 把整个文件夹放入 `%USERPROFILE%\.codex\skills\`。
4. 确保文件夹根目录直接包含 `SKILL.md`。

## 设计原则

- 最新要求优先，不混用新旧站位和道具状态。
- 先建立空间事实，再设计镜头。
- 关系镜头遵守全景中的真实位置。
- 近景裁掉其他人物不等于其他人物离开现场。
- 动作从上一状态自然发生，不瞬移、不穿模。
- 反应镜头服务剧情因果，不机械轮流切人。
- 特写放大画面，不改变道具的现实尺寸。
- 紧凑片段先删除冗余动作，不删正式台词。
- 输出采用自然换行，不添加无意义转义斜杠。

## 边界说明

这个仓库提供的是通用分镜决策方法和提示词结构，不包含任何具体项目的剧本、人物图片、私人路径或未授权素材。示例中的角色和时间参数只用于说明方法，不应机械复制到其他剧情。

实际生成结果仍会受到所用视频平台、模型版本、参考图质量、角色资产稳定性和单次生成时长影响。出现错误时，建议一次只修一个主要变量，并把最新有效尾帧作为下一次修改的连续性依据。
